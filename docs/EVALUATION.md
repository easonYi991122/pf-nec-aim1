# 评价合同

保留原 `evaluate.py` 的统计函数与 `harness_v3`／`harness_v2` 的评价逻辑；只改导入和缓存路径。删减版 spec 有独立校验和，原 spec 的身份保留在 provenance 中。随机种子模板、主指标、重复编号及完整确认对比族均不变。导出不提供该对比族全部历史训练臂，不能用删减后的最终模型集合宣称通过晋级。

预测表必须完整对应独立目标表：repeat、row_key、stay、y、pod、case；Task A另有fold。严禁通过内连接掩盖缺失预测。Task A每次先合并五折，才计算 AUROC；五次指标等权，不能把重复日合并视为独立样本。

PI72-CLEAN术前无阳性：总 AUROC = 术前阴性占全部阴性的比例 × 阳性对术前阴性 AUC + 其余比例 × 术后 AUROC。偏移方向由实际排序决定，不能仅根据术前全阴性推断。术前阶段内 AUROC为null。

Task A有术前阳性，因此必须分为四格：前阳性／前阴性、前阳性／后阴性、后阳性／前阴性、后阳性／后阴性。每格权重为该格正负配对数占全部正负配对数；各格贡献之和必须还原总体 AUROC。字段 `cross_stage_positive_vs_preop_negative_auc` 在 Task A比较**所有阳性**与术前阴性，不是纯术后阳性对术前阴性。

R11 的 A-D5-LGB 四格均值 AUC为 .54227/.14612/.96123/.70588，权重 .02653/.07666/.23059/.66622，还原总体 .71751。AP／Brier属于抽样保留日分布，不是部署校准。

`pf_nec.cli evaluate` 输出逐重复阶段指标、组成和分解、重复等权均值；`--harness`另调用 Task A冻结 harness。它只做最终参照复现，不重新生成已接受报告的完整比较族和同时区间。需要配对区间时调用 `evaluate.evaluate`，显式声明比较；其2000次住院分层共享bootstrap、至少1990次共同有效draw和完整家族晋级要求原样保留。MDD=.01，三重复screen须五重复确认。
