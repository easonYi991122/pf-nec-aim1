# 排除、依赖切断与能力边界

阶段接口：阶段 3 用 `stage3_cards` 汇总候选证据卡；阶段 4 用 `trial_skeleton` 和 `draft_dag` 形成试验与因果图草案，`rank_cards` 只按已约定规则排序。函数与输入结构见[探索入口](../explore/README.md)。

删减范围不重判既有科学结果。内部报告不随包分发，关键数字见 RESULTS。最终三条轻量梯度提升机（LightGBM）路径不依赖以下被排除的材料。

时间记号：术后日数（POD），手术当天从零计。

T3 的固定的十变量解释分组（PI10）是原冻结 spec 中依据内部论文表格整理记录（T007）表格整理的固定 10 变量解释组；不是从训练模型读取，也不开放对应源 bank learner。T007 为内部报告，不随包分发，相关用途已在此说明。

stage3_cards 不强制依赖 PI-29 模型，只读取调用者提供的汇总字段。没有某模型证据时必须缺省或 null，不能把其他部位归因移植过来；13 张卡的讨论顺序不能认证因果识别。trial_skeleton 与 draft_dag 仅支持支持因果草案的固定问题标识集合（STAGE4_IDS）的 9 个问题。所有原排除项持续生效。
