# 排除、依赖切断与能力边界

〔事实〕删减范围不重判既有科学结果。内部报告不随包分发，关键数字见 RESULTS。最终三条 LightGBM 路径不依赖以下被排除的材料。

|切断|原因|影响|
|---|---|---|
|PI 未发表代码、训练模型、读取／校验器及源码行审计|共享授权边界|不导出内容、权重、超参提取或源码转述|
|模型来源的 XGB learner|依赖排除的参数来源|只开放 LGB；不替换参数假装重现|
|PI-29 家族、源 bank 和依赖其的菜单|模型来源材料不导出|历史结果仍有效，但不能重跑原选择程序、序列、归因或学习曲线；不静默缩小菜单|
|原 spec 的机器路径、排除家族与调度说明|不是共享内容|保留已导出冻结 spec 的独立校验和及原规格来源身份；本修订不改冻结逻辑|
|原 CORE 驱动与导入时目录副作用|依赖旧工作区|仅保留纯行／划分／哈希函数和私有缓存接口|
|旧字典映射及数据派生 crosswalk|不分发数据字典或派生物|从授权 clean/raw 本地推导；歧义即失败|
|历史作业 DAG、dispatcher、设备／队列桥|不是本地复现必需|保留拟合池边界、停止轮数、ledger 和资源保护|

|I7 原曲线训练驱动|依赖排除家族|保留 8 背景变量及切片、嵌套抽样和统计；新曲线须另行冻结|

|历史序列／M1 完整选择菜单与作业调度|混有被排除输入及历史外测选择；不能静默删菜单冒充原程序|不提供原程序重跑；独立学习器及 D5-safe／GAIN 路径以新身份随包，见 TEAM_TASKS|
