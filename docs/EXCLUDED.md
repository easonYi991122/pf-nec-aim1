# 排除、依赖切断及影响

|切断|原因|对复现的影响|
|---|---|---|
|PI训练模型、读取／校验器、原作者源代码与源码行审计|不在本次共享授权范围|完全不导出；最终三条LGB路径不需要它们|
|从PI模型读取超参的XGB learner|超参来自排除的模型|树训练仅接受LGB；其它learner显式报错，不替换超参|
|PI-29特征家族、源特征bank与依赖其的菜单|特征列表来自排除的模型|不提供原历史菜单、序列、对应解释和学习曲线重跑；不静默缩小选择程序|
|原spec中的被排除家族、机器路径、历史调度说明|含非交接内容|生成明确标为删减版的冻结spec，使用独立内容hash；最终LGB配置、种子与评价规则保持不变|
|原CORE入口及其导入时目录初始化|依赖本机旧工作区与非导出模型|提取行／划分／哈希纯函数，使用单一配置和私有缓存接口|
|旧字典元数据／代码分组产物|数据字典和数据派生文件不随代码发布|从授权clean／raw输入在私有缓存重新推导必要映射；若不能唯一复现则报错|
|历史run DAG、dispatcher、review gate、设备桥与远端队列|本包只需本地最终模型路径|保留训练池边界、停止轮数、拟合记录与本地资源保护；队友自行管理作业|
|原T3全历史报告驱动|绑定不再导出的模型与历史证据|保留原interpret、t3_fast、G-safe编码／拟合hook，并提供最终模型只读解释packet入口；不复制原整轮报告|
|I7历史源模型曲线的训练驱动|其特征家族被排除|保留8背景变量及状态／累计切片训练、嵌套分层抽样与配对曲线统计；新模型曲线须另命名、另冻结|
|Aim 1b历史报告拼装／原始报告依赖|仅交接方法脚手架|保留测量、时序、资格、positivity诊断、试验和DAG定义函数；真实因果研究需独立协议，不提供效应估计|
|序列／M1／GPU模型代码|试过但未晋级；还会引入被排除的特征及调度依赖|文档保留状态，不增加最终模型的依赖面|
|真实数据、字典、缓存、权重、预测、行级日志、历史报告附件|代码共享边界|全部由获授权的数据在私有目录生成；本包只提供汇总结果|

T3保留原冻结spec中依据T007表格定义的固定10变量解释分组；不从PI训练模型读取，也不开放对应源bank训练臂。

PI72-CLEAN名称及clean-table合同本身重建了局部清理表规则，仍需项目负责人确认其对团队分享的范围。代码不声称恢复原论文完整设计。任何删减均不等于对已接受科学结论重新评估。
