## 时间轴与组别

〔事实〕`DOA0=入院日 → POD0=索引手术日 → POD k 日末预测 → 未来事件`；lead=事件日−预测日。模型输入只看预测时点已知信息；lead 归因是依将来事件分层的回顾性解释。

|组|首次登记 NEC 相对索引手术|formal|
|---|---|---|
|a|POD4–31|clean-linked 且仍在险时纳入|
|b|POD0–3|clean-linked 且仍在险时纳入；可产生术前 y3 阳性|
|c|手术前，但不早于入院|排除；术前辅助行 c_aux|
|d|POD>31|排除；窗口内辅助行 d_window|
|none|无已知首发日期|clean-linked 且符合行规则时纳入；不等于确认无 NEC|
|err|日期早于入院|排除|

late_aux 是晚期辅助日；locked 是已使用的历史时间留出；late_era 是较晚、可能截尾时期标记。Task B / B30 的 y30／yB30 是时点后 30 日首次 NEC，Bd 为日级版本；旧 yB 是时点后至 POD31 的版本，不能互换。本轮没有 Task B 训练路径。

## 补充：历史停点与标签

|术语|本包中的具体含义|
|---|---|
|C2 / STOP|历史输入时点敏感性工作的编号；此处特指删除 65 个时点待确认列的 3 次重复筛查。STOP 表示未达到原延伸门槛、停在筛查，不自动续跑或推翻历史结果；这些列不是已证实泄漏|
|DEC-008–010|历史决策链：DEC-008 定义受限搜索及预先固定组合，DEC-009 审计组件 G，DEC-010 规定该批结束后关闭 AUC 搜索；不是本轮重新开放的菜单|
|v2.5 锁定评价|对预先隔离的较晚时期住院进行的一次评价，已经使用；原留出住院随后进入 harness v3 开发池，当前没有未触碰的留出集|
|原 abc 目标|原计划从入院日末开始滚动预测首次 NEC，覆盖 a/b/c 的阳性组，包含术前首发 c；当前 clean-linked a/b/none formal 排除 c/d，不等于完成该目标|
|y3|Task A 的日标签：首次登记 NEC 是否在预测日之后 1–3 天发生；可有术前阳性日|
|outcome_3d|本地 clean 表保留的日标签；观察规则是每个合格病例在 max(0, NEC 日−3) 留 1 个阳性日。不是 y3 的别名，名称也不认证精确 72 小时提前量|
