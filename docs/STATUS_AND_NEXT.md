# 我们停在哪里，接下来先解决什么

本页区分事实、批准的规划决定与尚待冻结的研究建议；规划批准不等于真实运行或科学结论已获验收。依据：`ROUND_REDO_next_steps_zh.md`、`DEEPER_QUESTION_zh.md`、`ROUND_REDO_summary_zh.md`（内部报告，不随包分发；关键结论与数字已摘入）。已测结果见 [RESULTS](RESULTS.md)。

〔推断〕最重要的开放问题是模型用途尚未定义：谁在什么时点看到风险，随后会改变什么？现有区分度、AP 和重要性不能回答告警负担、床旁收益或治疗效果。术时风险分层、每日预警和因果干预研究需要不同的评价。

|优先工作|建议的下一步|回答的问题／边界|
|---|---|---|
|A1 用途对应的评价|〔建议〕先冻用途与内层阈值／校准规则，再报告风险分层和告警政策|已有历史告警负担描述；其阈值和 formal 人群不代表部署负担|
|A2 简单术时评分与日级模型|〔建议〕正式配对比较背景／术时模型和 G-safe；检验动态信息的增量|8 变量发现只是 3 次 screen，尚无对 G-safe 的配对检验|
|A3 留出整个中心|〔建议〕在历史中心留出基础上另冻新研究，检验迁移及编码依赖|E9-A-D5-site 已完成历史中心留出；不与住院划分求差，中心差异尚不能归因为登记差异|

〔事实〕随包 harness v3 提供 `fold_site`，将中心固定分为 5 组。历史 E9-A-D5-site 使用 harness v3 的 1×5 中心留出，AUROC 为 0.6950 [0.6732, 0.7174]；这是已完成的历史敏感性验证。本次最终模型报告使用按住院划分的 `fold_r*`；验证方案不同，不能相减。A3 的新方案仍须另冻。来源：运行登记 E9-A-D5-site，详见 [RESULTS](RESULTS.md)。

〔历史事实〕XGB-A-D5-phase_split 已在 formal 队列描述告警：每 100 病人日约 5.66 次，病例检出 0.25；阈值依据阴性日 5% FPR。这不是部署告警负担：formal 按未来结局筛选，阈值也不是按临床容量冻结。新评价须报告实际负担、检出、PPV、每检出 1 例的告警数和漏诊数，区分回顾性容量曲线与内层定阈值政策。来源：历史运行登记；harness v3 验证，告警计算沿用 harness_v2。

〔批准的决定〕A7 按 DEC-019 暂停主线结构搜索，是机会成本决定：既测结构假设未过冻结晋级门，在已用拆分上继续选择会累积分叉，且 PI 尚未固定用途，主指标可能改变。它不援引饱和停止规则：规则要求每病例翻倍的斜率 <0.005，描述性实测约 +0.03，因此第一条件不成立；观测范围为 71–285 个训练病例、3 次重复、历史单一配方。暂停不证明结构无用或数据量是唯一瓶颈。重启须有可区分机制并冻结指标／预算／停点，或用途改变主指标，或新信息源支持；新架构名称或新种子本身不够。队友 T-2/T-3 可按独立冻结卡研发。

〔批准的意向〕D1：不从已用于开发的数据另切“未触碰留出集”；只登记今后新增数据的隔离意向，访问与训练／选择日志先封存，由主控另冻独立评价合同。现有 r1–5／r0–4 结果均为复现／开发证据。

〔字典事实〕ProcLoc 9 = Cardiac OR（心脏手术室），不是中心编码；G-safe 的中心编码为 site_eb。来源：授权数据字典的 ProcLoc 条目。

队友合同与前置门见 [TEAM_TASKS](TEAM_TASKS.md)；D3 保留 PI10 为解释组，不开放对应学习器。

〔历史更正〕POD0–2 的 TCN 对 w7-R1 树为 −0.0026；对无序 MLP 的 +0.0416 并非 16 个序列格的最大值，POD8–14 对 w7-R1 树为 +0.0462。这些格为未跨 POD 多重校正的描述，不能选择最大格作主终点。M1 菜单含 GAIN50，r1 GRU-D 选 GAIN50-w7；来源节名见 [RESULTS 历史更正表](RESULTS.md)。

〔推断〕I7 学习曲线提示样本量可能是限制之一；它没有排除结构、优化和测量限制，也不能保证扩样获益。

## Aim 1b：建议排序与待 PI 确认

〔建议〕胸骨关闭时机为主候选；外周动脉线拔除时机为条件性备选；脐动脉线继续 keep，通气后置，药物仅作快照对照。这是讨论排序，尚未冻结主问题，也未估计治疗效应。

〔推断〕支持上述排序的已测可行性证据来自 `a2/report.md`（内部报告，不随包分发；关键数字已摘入）：展示参照为 POD3、1 日宽限。胸骨关闭在 42/61 个中心双臂各有至少 5 次住院，最大 SMD 从 0.24 降至 0.07，可用事件 92–93；外周动脉线倾向分尾部为 45.5%，加权后最大 SMD 仍为 0.67，可用事件 177–183，残余不平衡是其仅作条件性备选的限制。全部候选有严重度代理风险；准备度、血流动力学趋势、肠灌注未测。事件数不是功效证明，低 SMD 也不证明可交换性；不得按此表挑最佳干预日。

〔建议〕冻结前请 PI／临床方回答以下 7 问（源自 `a2/report.md` §4）：

1. 哪类患儿、哪次可记录准备度评估允许两种选择？能否补循环／灌注、镇静、呼吸参数和症状起点？
2. 拔指定一根线还是撤全部监测？是否允许替代／再置入？通气终点是真计划拔管、胸骨终点是真关闭吗？
3. 日历日、手术结束、ICU 入科、24h 指哪个临床时点？能否确认地点、记录可见时间与同日先后？
4. 两臂执行、最多 2 种宽限期、救治阈值和偏离规则是什么？药物的剂量阶梯／共同治疗史是什么？首 2h 快照不能代替分配。
5. Bell 标准、首次／复发 NEC、院内 POD31 目标、死亡／出院处理与最小有意义差异是什么？
6. 中心／指征内无双臂支持时，接受什么限制人群？复杂倾向模型或截权不能弥补未测混杂。
7. 正式效应分析怎样设置独立确认和多重比较边界？最终 1 主 + 1 备由 PI／主控冻结。

〔建议〕未冻结前停在协议／可行性阶段；改动预测模型输入所得分数不能称为治疗效应。

## 方法学线索与 Aim 2

〔建议〕B2 可发展为围术期评价方法学讨论：在 PI72-CLEAN 中，实测跨阶段排序使总体 AUROC 比术后约高 0.08；Task A 的术前阳性对术后阴性项则抵消部分相反方向贡献。偏移来自组成与**实际排序共同作用**，不是术前全阴性必然造成。公式与四格见 [EVALUATION](EVALUATION.md)。来源：`ROUND_REDO_next_steps_zh.md`、`r9/report.md`、`r11/report.md`。
