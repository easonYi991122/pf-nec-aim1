# 我们停在哪里，接下来先解决什么

划分字段：`fold_site` 是固定中心分组；`fold_rN`（模式 `fold_r*`）是第 N 次按住院划分的折号。`harness_v3` 是该划分及评价的实现版本，`harness_v2` 指历史告警计算所用的前一实现版本；两者不可仅凭名称互换。

本页把已有证据、共同规划和尚待讨论的问题分开说明。当前状态仅依据 2026-10-07 已复核研究汇总更新；历史部分保留 `ROUND_REDO_next_steps_zh.md`、`DEEPER_QUESTION_zh.md`、`ROUND_REDO_summary_zh.md` 的原始来源身份（内部报告，不随包分发，关键内容已摘入）。详细结果见 [RESULTS](RESULTS.md)。

本轮信息阶梯、预警和中心留出评价已完成，现有日级参照（A-D5-LGB）保留，没有模型晋级。结论以仍未解决的 64 列在预测时可用为条件；独立单位为住院而非患者，缺少可靠跨住院患者标识；研究人群是按未来结局筛选的开发队列（formal）。证据为回顾性内部交叉验证，尚无外部验证。共同附录已安装并冻结为 v1.2（2026-10-07），术后首日风险分层任务（T-4）不再因附录而阻塞；术后首日分层已复核，没有明确增益；短期终点估计不可靠。告警档位是研究选择，不是首席研究者（PI）认可的临床阈值。

我们的解释是：最重要的开放问题是模型用途尚未定义：谁在什么时点看到风险，随后会改变什么？现有区分度、平均精确率（AP）和重要性不能回答告警负担、床旁收益或治疗效果。术时风险分层、每日预警和因果干预研究需要不同的评价。

历史记录：日级任务按术前术后分开的历史极端梯度提升配置（XGB-A-D5-phase_split）已在 formal 队列描述告警：每 100 病人日约 5.66 次，病例检出 0.25；阈值依据阴性日 5% 假阳性率（FPR）。这不是部署告警负担：formal 按未来结局筛选，阈值也不是按临床容量冻结。新评价须报告实际负担、检出、阳性预测值（PPV）、每检出 1 例的告警数和漏诊数，区分回顾性容量曲线与内层定阈值政策。来源：历史运行登记；harness v3 验证，告警计算沿用 harness_v2。

## 第一研究目标中的目标试验模拟部分（Aim 1b）：建议排序与待 PI 确认

建议：胸骨关闭时机为主候选；外周动脉线拔除时机为条件性备选；脐动脉线继续 keep，通气后置，药物仅作快照对照。这是讨论排序，尚未冻结主问题，也未估计治疗效应。

我们的解释是：支持上述排序的已测可行性证据来自 `a2/report.md`（内部报告，不随包分发；关键数字已摘入）：展示参照为 POD3、1 日宽限。胸骨关闭在 42/61 个中心双臂各有至少 5 次住院，最大标准化均数差（SMD）从 0.24 降至 0.07，可用事件 92–93；外周动脉线倾向分尾部为 45.5%，加权后最大 SMD 仍为 0.67，可用事件 177–183，残余不平衡是其仅作条件性备选的限制。全部候选有严重度代理风险；准备度、血流动力学趋势、肠灌注未测。事件数不是功效证明，低 SMD 也不证明可交换性；不得按此表挑最佳干预日。

建议：冻结前请 PI／临床方回答以下 7 问（源自 `a2/report.md` §4）：

1. 哪类患儿、哪次可记录准备度评估允许两种选择？能否补循环／灌注、镇静、呼吸参数和症状起点？
2. 拔指定一根线还是撤全部监测？是否允许替代／再置入？通气终点是真计划拔管、胸骨终点是真关闭吗？
3. 日历日、手术结束、重症监护室（ICU）入科、24h 指哪个临床时点？能否确认地点、记录可见时间与同日先后？
4. 两臂执行、最多 2 种宽限期、救治阈值和偏离规则是什么？药物的剂量阶梯／共同治疗史是什么？首 2h 快照不能代替分配。
5. 临床坏死性小肠结肠炎分级标准（Bell）标准、首次／复发坏死性小肠结肠炎（NEC）、院内 POD31 目标、死亡／出院处理与最小有意义差异是什么？
6. 中心／指征内无双臂支持时，接受什么限制人群？复杂倾向模型或截权不能弥补未测混杂。
7. 正式效应分析怎样设置独立确认和多重比较边界？最终 1 主 + 1 备由研究伙伴与 PI 共同确定。

建议：未冻结前停在协议／可行性阶段；改动预测模型输入所得分数不能称为治疗效应。
