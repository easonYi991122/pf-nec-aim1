# Exclusions, dependency cuts and supported scope

Stage interfaces: stage 3 uses `stage3_cards` to collect candidate evidence cards; stage 4 uses `trial_skeleton` and `draft_dag` for trial and causal-graph drafts, while `rank_cards` follows the agreed ordering rules. See [exploration](../../explore/README.en.md) for functions and inputs.

Export reduction does not reassess prior scientific results. Internal reports are not shipped; key numbers are in RESULTS. The final Light Gradient Boosting Machine (LightGBM) paths do not depend on the following excluded material.

Time notation: postoperative day (POD), counted from zero on surgery day.

|Cut|Reason|Effect|
|---|---|---|
|Unpublished principal investigator (PI) code, trained model, loading / checking tools and source-line audit|Sharing boundary|No content, weights, parameter extraction or source paraphrase exported|
|Model-derived extreme gradient boosting learner code (XGB) learner|Excluded parameter source|Only Light Gradient Boosting Machine learner code (LGB) is exposed; parameter substitution defines a new configuration and does not reproduce the original one|
|source-model feature family excluded from the package (PI-29) family, source bank and dependent menus|Model-derived material excluded|Historical results remain valid, but original selection, sequence, attribution and learning-curve fits cannot be rerun; no silent menu reduction|
|Machine paths, excluded families and orchestration text in the original spec|Outside sharing scope|Keep the already-exported frozen spec's own checksum and original-spec provenance; this revision does not change frozen logic|
|Original historical name for local cleaned-table row and sampling interfaces (CORE) driver and import-time directory side effects|Old-workspace dependency|Retain only pure row / split / hash functions and private-cache interfaces|
|Old dictionary mappings and data-derived crosswalks|Dictionary / derivatives not distributed|Infer locally from authorised clean/raw inputs; ambiguity fails|
|Historical job directed acyclic graph (DAG), dispatcher, device / queue bridges|Not needed for local reproduction|Retain fitting-pool boundaries, stopping rounds, ledger and resource guard|
|Full historical attribution module (T3) report driver|Bound to excluded models / evidence|Retain interpret, t3_fast and availability-gated encoding-enhanced feature scheme (G-safe) read-only packet methods, not full historical report reconstruction|
|historical feature-slice, window, sequence and learning-curve diagnostic program (I7) original curve-training driver|Excluded family dependency|Retain 8-background-variable slices, nested sampling and statistics; freeze new curves separately|
|target-trial-emulation component of the first research aim (Aim 1b) historical report assembly / evidence loading|Methods-only handoff|Support measurement, timing, eligibility, positivity, stage3_cards, trial_skeleton, draft_dag and rank_cards; schema in explore/README; no bundled historical evidence or effect estimate|
|Historical full sequence / historical neural-model selection family (M1) selection menus and scheduling|Mix excluded inputs with historical outer-test selection; reducing the menu changes the selection procedure; an agreed restricted menu requires a new identity and separate interpretation|Original programs cannot be rerun; independent learners and daily availability-gated registry feature bank (D5-safe) / feature ranking by tree gain within the current training pool (GAIN) paths ship under new identities; see TEAM_TASKS|
|Full historical reconstructed feature-bank name (D5) neural input: not shipped|The frozen window gate prohibits full-bank multi-day concatenation; the sequence representation with values, missingness bits and row-availability bits (R4) channel cap also excludes the full bank|Retain child-local top fifty columns ranked by training-pool gain (GAIN50) from D5-safe and existing full-column tree references; do not modify the window gate|
|Complete new-task drivers: not shipped|Scoring masks, joint family, alert policies and real-run arrangements need checking against each task contract|Only single-fit / apply interfaces; POD0–2 scoring adapter, joint comparisons and new landmark risk-stratification task (Task B) driver are not shipped; prototypes cannot claim execution of new tasks|
|Data, dictionary, caches, weights, predictions, row logs, hosts / credentials and internal agent tools|Code-sharing boundary|Patient-level outputs remain in authorised private locations|

T3 fixed ten-variable interpretation group (PI10) is a fixed 10-variable interpretation group in the original frozen spec, assembled from internal manuscript-table organization record (T007) tables; it is not read from a trained model and exposes no source-bank learner. T007 is an internal report, not shipped; its relevant use is explained here.

stage3_cards does not require a PI-29 model; it reads caller-supplied aggregate fields. Missing model evidence must remain absent or null, not be borrowed from another anatomical site; the discussion order of 13 cards does not establish causal identification. trial_skeleton and draft_dag support only the 9 questions in fixed set of question identifiers supported by causal drafts (STAGE4_IDS). All original exclusions remain in force.
